# MoveMentor · 安全边界与免责声明

> 这个项目面向老年人、膝痛人群、轮椅使用者和慢病人群。**它距离「医疗建议」只有一步之遥，而这一步是不能跨的。**
> 本文档规定措辞、列出禁止表述、给出可直接复制的免责声明，并说明我们**没有**做什么。

| 一个把动作改写成**低冲击变式**的规则引擎 | 一个诊断工具 |

| 禁止 | 原因 |
| --- | --- |
| 「**安全**的」「**安全版**」 | 安全是一个需要证据的词。我们没有做过任何安全验证 |
| 「**医疗有效**」「有疗效」 | 涉及医疗器械声称，属于监管范畴 |

## 四、我们**没有**做什么（诚实清单）

写在这里比被评审问出来好：

| 没做的 | 后果 / 影响 |
| --- | --- |
| **没有临床验证** | 所有阈值都是工程取舍，不是医学结论 |
| **没有医学顾问参与设计** | 规则表可被医生审阅，但尚未经过审阅 |
| **没有个体化评估** | 人群参数是**群体性**的，「膝痛人群」内部差异极大 |
| **没有接入生理信号** | 没有心率、血氧、主观疲劳度，无法根据实时状态调整强度 |
| **没有疲劳/风险实时监测** | 引擎只判断「动作到不到位」，不判断「该不该继续」 |
| **没有处理急性疼痛场景** | 运动中报告疼痛时应立即停止，这不是本工具能判断的 |
| **没有 MP / 禁忌症筛查** | 未做运动前健康筛查问卷（如 PAR-Q） |
| **没有轮椅适配的解剖学验证** | 「坐姿版本」是动作模式上的合理改写，未针对脊髓损伤等具体状况做验证 |
| **没有多帧滤波之外的平滑** | 姿态估计在遮挡、宽松衣物下会漂移 |
| **没有覆盖全部动作** | 规则表只有 9 个动作 / 4 类人群 / 9 条映射，是「可运行的闭环」而不是「完整数据库」 |

## 五、参数从哪来

规则表里的数值（比如膝痛人群的 `limit knee_left<=105`）取的是**保守方向**，来源是：

1. **动作生物力学的常识性区间**：比如日常坐站转移时膝关节屈曲大致在 90°–105° 区间，取 105° 作为一个偏保守的上限；
2. **低冲击运动的通行做法**：去掉腾空与落地、去掉地面俯卧、去掉深蹲到底，用支撑（椅背、墙面）替代；
3. **对人群差异的冗余**：人群参数是群体性的，取保守值是为了让「个体差异较大的情况」也不至于落在明显不合适的区间。

**这些都不是临床结论。** 它们的作用是让翻译器输出一个**保守的起点**，而不是替代专业评估。

## 七、如果要在真实场景部署，还需要做什么

按重要性排序：

1. **医学审阅规则表**：请康复科医生或治疗师逐条审阅 9 条映射与人群参数；
2. **加运动前筛查**：接入 PAR-Q 或类似的健康筛查问卷，把「不适合运动」的人挡在流程之外；
3. **加实时风险兜底**：出现疼痛自述、异常姿态（如突然失衡）时立即中断；
4. **个体化而不是群体化**：让人群参数成为**起点**，由用户或治疗师调整；
5. **做可用性测试**：老年用户的实际使用测试（字号、语音速度、引导方式）；
6. **做临床验证**：在任何「有效」声称之前，必须有对照研究支持。

**在这些完成之前，本工具保持现在的定位：一个可被专业人士审阅的、保守的动作改写辅助工具。**
