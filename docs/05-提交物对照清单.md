### ① MoonBit 为主 ✅

**证据**

- **核心引擎 `src/engine/`**：2813 行生产代码 + 996 行测试，全部是 `.mbt`。DSL 解析器、约束求解器、计数状态机、指导语生成、合成姿态源、JSON 序列化，**没有一行 JavaScript**。
- **桥接层 `src/bridge/api.mbt`**：380 行 MoonBit，含两个 `extern "js"` FFI（语音合成、高精度计时）。
- **命令行工具 `cmd/main/main.mbt`**：217 行 MoonBit。
- **演示层 `web/`**（HTML/CSS/JS 635 行）是唯一的前端代码，且**不含任何翻译或计数逻辑**——它只做三件事：取姿态、画骨架、调引擎。

## 三、复现步骤（评委视角，从克隆到看到结果）

```bash
# 0. 前置：安装 MoonBit 工具链（需要 moon 与 moonc --version）
moon version

# 1. 克隆
git clone <仓库地址> && cd MoveMentor

# 2. 跑测试（约 10 秒，无需网络与摄像头）
moon test --target js
#    期望：Total tests: 69, passed: 69, failed: 0.

# 3. 跑引擎自检
moon run cmd/main --target js
#    期望：9 条翻译规则全部打勾；general 人群恒等映射；
#          离线演示跑出确定的计次；反向翻译列出源动作

# 4. 构建引擎的 JS 产物 + 验证 JS 互操作
moon build --release --target js
node scripts/smoke.mjs
#    期望：冒烟测试全部通过。

# 5. 打开演示页面
python -m http.server 8000
#    浏览器打开 http://localhost:8000/web/
#    保持「姿态来源 = 合成姿态（无需摄像头）」，点「开始翻译」
```

> **第 5 步不需要摄像头与网络**。摄像头模式（MediaPipe）是可选功能，首次使用需联网下载模型。
